# OBS ギフト案内 UI / Version6-6

既存の `http://127.0.0.1:8765/overlay` をそのまま使用します。
1080×1920、背景透過。楽曲情報は左36・上170px、左右のパネルは端36・上280px、幅250px。
提供HTMLのネオン配色・斜めカット・走査線・フォントを使用し、プレビュー用の背景、
中央のガイド枠、下部の説明、サンプル名・数値を除いて実データへ接続しました。

- 左ATTACK、右上SHIELD。試練中のみ右下RESCUEを表示しSHIELD位置は固定。
- 両サービスのギフト名・単価を表示。`gift-map.json` の `image_url` を設定すると実画像に
  置換。YouTubeのマイク・やる気満々は確認済みの公式画像を表示。画像未提供時は、参照デザインと同様のSVGアイコン。
- ランク・同接・NOTE ATTACKは非表示。中央BPM・メーターは引き続きゲーム側で描画。
- `/overlay?mode=light` の既存SCREEN合成、音楽の拍に追従する光り方は維持。
- 1個で成立する効果の貢献ゲージは非表示。2個以上は現在の必要個数と貢献数を表示。
- `attack_required_units` は現在の攻撃価格。予告開始で倍増、取り消し後の再予告では
  同一グループを二重カウントしない。曲の開始で基準へ戻し、未使用単位を再集計。
- SHIELDは無試練時に待機。待機の名前・枚数・残り受付回数はAPIから表示。
  予告は通常通り進み、試練開始時にCLEARへ。保護中の追加盾は次の試練まで待機し、
  保護時間を連結しない。使われなかった盾・端数は次曲に持ち越す。
- RESCUEは受信直後の送信者と単価×個数を短く表示。同じ人の同単価の連打は合算。
